# System Architecture Overview

This document provides a high-level overview of the National Genomics Infrastructure (NGI) system architecture.

## Core Components

### Sequencing Cluster

The sequencing cluster consists of:

- 4x Illumina Nova 6 sequencers
- Standard flow cells: 2x 10.5B (HiSeq), 1x 4.7B (MiSeq)
- Maximum throughput: ~12 Tbps per flow cell

### Storage Infrastructure

- **Hot storage**: 2 PB NVMe-based shared filesystem (`/proj/fs001`)
- **Near-line**: 15 PB LTO tape for backup and archive
- **Data retention**: Raw data kept for 10 years, processed data for 5 years

### Compute Resources

- Login nodes for interactive work
- HPC batch system with 10,000+ cores available
- GPU nodes for AI-based image analysis
